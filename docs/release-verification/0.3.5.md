## Production compatibility correction

The replacement must preserve the distinction between `device_serial` and `device_index` after
configuration loading. A value sourced from `device_index` must remain an index even when its
zero-padded decimal form also matches the lexical shape of an RTL-SDR serial. A value sourced from
`device_serial` must remain a strict serial selection and must not silently fall back to an index.

That selector type must remain bound through plugin initialization, scheduler registration,
device claim, re-enumeration refresh, contention handling, and release. Regression coverage must
exercise both interpretations of the same numeric-looking value, canonical duplicate-claim
protection, scheduler forwarding, and affected plugin paths.

The selector correction is present at the tagged commit and its source CI passed. This does not
substitute for a complete signed artifact, production transaction, physical hardware sequence, or
soak. Neither 0.3.4 nor 0.3.5 evidence may be relabeled or carried forward as 0.3.6 qualification.
